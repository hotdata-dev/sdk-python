# DiscoveryStatus

Result of looking up a new connection's tables. A `managed` connection declares its tables, so this is always `skipped`.

## Enum

* `SUCCESS` (value: `'success'`)

* `SKIPPED` (value: `'skipped'`)

* `FAILED` (value: `'failed'`)
